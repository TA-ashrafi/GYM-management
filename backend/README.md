# ALPHA FITNESS Backend API

Backend REST API for ALPHA FITNESS Gym Management System built with Bun, Express, and Supabase.

## Features
- Authentication & User Authorization
- Members Management & RFID Subscriptions
- Attendance Tracking & Scans
- Store Inventory & Profit Tracking
- Expense Tracking
- Branch Multi-tenancy Management

## Setup
1. Install dependencies:
   ```bash
   bun install
   ```
2. Configure `.env`:
   ```
   PORT=3000
   SUPABASE_URL=your_supabase_url
   SUPABASE_ANON_KEY=your_supabase_anon_key
   ```
3. Run development server:
   ```bash
   bun run dev
   ```
