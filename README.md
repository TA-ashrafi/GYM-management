# ALPHA FITNESS — Your GYM Operating System

ALPHA FITNESS is a high-performance gym management platform built with a modern micro-architecture separating client and backend services.

## Architecture & Features
- **Frontend App**: React 19, TypeScript, TanStack Router, and Tailwind CSS.
- **Backend API**: Bun, Express, and Supabase integration with structured services, controllers, routes, and authentication middleware.
- **RFID Real-time Attendance**: Live scan tracking and automatic check-in processing.
- **Store & Inventory**: Net profit tracking and store inventory analytics.
- **Multi-Branch Operations**: Seamless multi-gym management and isolation.
